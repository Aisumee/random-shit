# ASCII Christmas Tree

A rotating 3D Christmas tree made of ASCII letters. It grows in snow-capped, then gets gold garlands, baubles, 170 fairy lights, a star with light rays, presents and a tree skirt, with snow falling throughout and a cat asleep under the tree.

- **Web:** open `index.html` in a browser. Tap the tree to restart.
- **Terminal:** `pip install numpy`, then `python3 tree.py`. Press Ctrl+C to quit. Needs a terminal with true-colour support.
