# ASCII Christmas Tree

A rotating 3D Christmas tree made of about 16,000 ASCII letters, with snow, twinkling lights, a starfield and a star on top.

- **Web:** open `index.html` in a browser. Tap the tree to restart.
- **Terminal:** `pip install numpy`, then `python3 tree.py`. Press Ctrl+C to quit. Needs a terminal with true-colour support.
